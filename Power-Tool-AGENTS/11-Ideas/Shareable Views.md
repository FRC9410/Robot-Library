# Shareable Views

**Status:** Proposed, 2026-10-30.

## Idea
Export a layout plus a time range (and any notes) as a small file. Someone else opens it with the
same log and sees exactly the same view.

## Why
Makes "look at this" between teammates or mentors one step.
