# SimManager.java Template

## Critical API Corrections

1. `GamePieceInfo` is a NESTED record inside `GamePieceOnFieldSimulation`, not standalone.
   Import: `import org.ironmaple.simulation.gamepieces.GamePieceOnFieldSimulation.GamePieceInfo;`

2. Shape is a dyn4j `Convex` object:
   - Cylinder: `new Circle(Inches.of(radius).in(Meters))`
   - Box: `new Rectangle(Inches.of(length).in(Meters), Inches.of(width).in(Meters))`

3. `getGamePiecesArrayByType()` returns `Pose3d[]` NOT `Pose2d[]`.
   Use `StructArrayPublisher<Pose3d>` and `Pose3d.struct`.

4. Do NOT add `SimManager.update()`. Physics runs in `Robot.simulationPeriodic()` via
   `MapleSimSwerveDrivetrain.simulationPeriodic()`. Adding another call here double-ticks.

## How to fill {{GAME_PIECE_TYPE_CONSTANTS}}

```java
private static final String BALL_TYPE = "Ball";
```

## How to fill {{GAME_PIECE_INFO_CONSTANTS}}

Cylinder (radius in inches):
```java
private static final GamePieceInfo BALL_INFO = new GamePieceInfo(
    BALL_TYPE,
    new Circle(Inches.of(2.955).in(Meters)),   // radius as meters
    Inches.of(5.91).in(Meters),                // height as meters
    Kilograms.of(0.227),
    0.8,   // linear damping
    0.8,   // angular damping
    0.3);  // coefficient of restitution
```

Box (length x width in inches):
```java
private static final GamePieceInfo CORAL_INFO = new GamePieceInfo(
    CORAL_TYPE,
    new Rectangle(Inches.of(12.0).in(Meters), Inches.of(8.0).in(Meters)),
    Inches.of(6.0).in(Meters),
    Kilograms.of(0.18),
    0.8, 0.8, 0.3);
```

## How to fill {{INIT_PUBLISHERS}}

```java
ballPosesPublisher = NetworkTableInstance.getDefault()
    .getStructArrayTopic("Simulation/BallPoses", Pose3d.struct)
    .publish();
```

## How to fill {{PUBLISH_POSES_BODY}}

```java
if (ballPosesPublisher != null) {
    // getGamePiecesArrayByType returns Pose3d[] directly
    ballPosesPublisher.set(
        SimulatedArena.getInstance().getGamePiecesArrayByType(BALL_TYPE));
}
```
