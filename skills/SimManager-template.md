## Critical: Correct GamePieceInfo API

The `GamePieceOnFieldSimulation` constructor does NOT take direct dimensions.
It takes a `GamePieceInfo` record. The shape is a dyn4j `Convex` object:
- Cylinder: `new Circle(radiusInMeters)` from `org.dyn4j.geometry.Circle`
- Box: `new Rectangle(lengthInMeters, widthInMeters)` from `org.dyn4j.geometry.Rectangle`

Convert inches to meters when building the shape: divide by 39.3701 or use
`Inches.of(x).in(Meters)`.

### GamePieceInfo record

```java
private static final GamePieceInfo {{NAME_UPPER}}_INFO = new GamePieceInfo(
    "{{Name}}",                          // type name string
    new Circle({{RADIUS_METERS}}),        // or new Rectangle(length, width) for box
    {{HEIGHT_METERS}},                    // height in meters
    Kilograms.of({{MASS_KG}}),           // mass
    {{LINEAR_DAMPING}},                   // linear damping (default 0.8)
    {{ANGULAR_DAMPING}},                  // angular damping (default 0.8)
    {{COEFFICIENT_OF_RESTITUTION}}        // bounciness (default 0.3)
);
```

### GamePieceOnFieldSimulation constructor

```java
new GamePieceOnFieldSimulation(
    {{NAME_UPPER}}_INFO,
    new Pose2d({{X_METERS}}, {{Y_METERS}}, new Rotation2d())
)
```

## How to fill {{GAME_PIECE_INFO_CONSTANTS}}

For each game piece, generate one `GamePieceInfo` constant.

Cylinder example (Note, radius 7 inches, height 2 inches):
```java
private static final GamePieceInfo NOTE_INFO = new GamePieceInfo(
    "Note",
    new Circle(Inches.of(7.0).in(Meters)),
    Inches.of(2.0).in(Meters),
    Kilograms.of(0.235),
    0.8,
    0.8,
    0.3
);
```

Box example (Coral, 12x8 inches footprint, height 6 inches):
```java
private static final GamePieceInfo CORAL_INFO = new GamePieceInfo(
    "Coral",
    new Rectangle(Inches.of(12.0).in(Meters), Inches.of(8.0).in(Meters)),
    Inches.of(6.0).in(Meters),
    Kilograms.of(0.18),
    0.8,
    0.8,
    0.3
);
```

## How to fill {{GAME_PIECE_PUBLISHERS}}

private static StructArrayPublisher<Pose2d> notePosesPublisher;

## How to fill {{INIT_PUBLISHERS}}

Initialize each publisher in initialize():
```java
notePosesPublisher = NetworkTableInstance.getDefault()
    .getStructArrayTopic("Simulation/NotePoses", Pose2d.struct)
    .publish();
```

---

## How to fill {{PUBLISH_POSES_BODY}}

One block per game piece type:
```java
if (notePosesPublisher != null) {
    notePosesPublisher.set(
        SimulatedArena.getInstance()
            .getGamePiecesArrayByType("Note")
            .stream()
            .map(GamePieceOnFieldSimulation::getPose)
            .toArray(Pose2d[]::new)
    );
}
```

## How to fill {{SPAWN_GAME_PIECES_BODY}}

);
SimulatedArena.getInstance().addGamePiece(
    new GamePieceOnFieldSimulation(NOTE_INFO, new Pose2d(2.0, 6.5, new Rotation2d()))
