# Auto Path Overlay

**Status:** Proposed, 2026-10-30.

## Idea
On the field widget, draw the planned auto path next to the robot's actual `Drive/Pose` trail.

## Why
Shows right away where an auto drifted off its path.

## Open questions
- Where does the planned path come from? Autos are built in code (`AutoBuilder`), so the robot may need to log the path it's following.
