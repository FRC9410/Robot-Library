# One Widget System Everywhere

**Status:** Proposed, 2026-10-30.

## Idea
Make the Drive tab a saved layout built from the same widgets as the log viewer, so live
driving and replay look the same.

## Why
- One set of widgets to maintain.
- Teams could customize the Drive tab by dragging widgets instead of editing `power-tool/dashboard/`.
