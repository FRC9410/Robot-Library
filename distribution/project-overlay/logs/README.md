# Robot logs

Power Tool uses this folder as the default local log library. In **Logs → Get logs from robot**, select runs to download. **Download and open** saves a local copy here and opens it for playback. You can also place `.wpilog` and `.hoot` recordings here to browse them in Log Viewer.

Use **Change** in Log Viewer to choose a different library folder. Power Tool remembers your selection on this computer.

Git ignores the recordings and subfolders here and keeps this README. Keep any logs you want to share in a separate archive or file share.
