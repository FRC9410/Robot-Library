# Match List

**Status:** Decided. Built in v1 (2026-10-31): period chips in the Logs tab top bar, from `Drive/Mode`.

## Idea
When a log opens, split it into enable periods using `Drive/Mode` and `Drive/Enabled`. List them
as clickable entries like "Q42 auto" and "Q42 teleop". Clicking one zooms the timeline to that period.

## Why
Most of a log is the robot sitting disabled. This skips straight to the parts that matter.
